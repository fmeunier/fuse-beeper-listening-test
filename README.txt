ZX Spectrum beeper listening comparison
=======================================

This is a blinded comparison of experimental Fuse beeper emulation with
recordings from real ZX Spectrum hardware. It contains 18 short comparisons
and usually takes about 10-15 minutes.

For each trial, listen to the hardware Reference and emulator samples A and B,
then choose the emulator sample that sounds closer to the reference. “No
meaningful preference” is a valid and useful response. Headphones or decent
speakers are recommended, but specialist equipment is not required.

Open index.html in a current browser to begin. The package is also suitable for
ordinary static web hosting. If your browser restricts audio or local storage
when opened directly, run this command in this directory and visit the shown
address:

    python3 -m http.server 8000

Then open http://localhost:8000/ in your browser.

Your progress is stored only in the browser. No account is needed, and no
analytics or automatic upload is used. At the end, choose “Download Results”
and return the downloaded JSON file to the researcher using the method given
with the test.
